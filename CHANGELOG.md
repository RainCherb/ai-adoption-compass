# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.4.0] — 2026-10-25

### Добавлено

* График API-бюджета с разбивкой вход/выход и масштабами месяц, 1 000 запросов и год; те же серверные цены, что в карточках.
* Серверные сценарии портфеля и интерактивный график накопленного эффекта с внедрением в месяце 0, тремя линиями и точными суммами выбранного месяца.
* Сведения о сценариях применения, максимальном выходе, версии, доступе в России и официальных источниках.

### Изменено

* Только API: локальные предложения исключены из сервиса, интерфейса и политики выбора; явные REST-запросы локальных моделей возвращают 422.
* Claude/OpenAI: официальный API в России недоступен. DeepSeek: подтверждения прямого API-доступа из РФ в первоисточниках нет; неизвестный статус не подменён обещанием.
* Локальные измерения перенесены в архив документации; публичный endpoint возвращает 410. Раздел качества показывает экспертную матрицу и план API-пилота.

## [1.3.0] — 2026-10-25

### Исправлено

* Убрана отдельная вкладка зарубежных моделей. Sonnet 5.5, GPT-6.1 Sol и DeepSeek V4.1 Flash стали основой подбора, всех 18 процессов демо, ROI, сценариев и отчётов.
* Один проверяемый тарифный профиль для всех расчётов; экспертные оценки отделены от собственных измерений.
* Сравнение всех трёх моделей в карточке каждого процесса и отчёте; USD, RUB, API ID, источники, лимиты и причины исключения.
* Глобальные настройки приоритета, периода DeepSeek и допущения поддерживаемого региона. Политика ПДн сохранена; демопроцессы используют открытые/вымышленные данные.
* Просроченные или изменённые источники исключаются из подбора и ROI; прямой API не вызывается.

## [1.2.0] — 2026-10-24

### Добавлено

* Главный экран зарубежных моделей в порядке Sonnet 5.5 → GPT-6.1 Sol → DeepSeek V4.1 Flash.
* Прямые тарифы API с официальными model IDs, лимитами, условиями и закреплёнными SHA-256 источников.
* Единый калькулятор USD без кэша: Peak/Off-peak DeepSeek, порог длинного контекста GPT, проверка лимитов и скрытие стоимости при устаревшем ревью.
* Явное разделение тарифного сравнения, условного экспертного каталога и прежних измерений компактных LLM.

## [1.1.0] — 2026-10-24

### Добавлено

* Публичный read-only demo mode без SQLite, пользовательских загрузок и общего журнала; лимиты запросов и тела,
  предзагруженные 18 процессов, конфигурация Render Free, явное объяснение обработки данных.
* Реальные измерения трёх локальных LLM на 72 примерах: полные ответы, версии и хеши весов/runtime, параметры,
  проверка целостности артефакта, отдельная вкладка и REST API; симуляция сохранена как учебный режим.
* Реестр источников тарифов/доступа, нормализованные предложения OpenRouter, срок актуальности и происхождение,
  ревью с привязкой к SHA-256, еженедельный артефакт-кандидат без автоматической подмены каталога.

### Исправлено

* Ошибка 500 при переполнении расчёта очень большой стоимостью внедрения: введены числовые пределы и безопасные ошибки 422.
* Ошибочный формат usage провайдера обрабатывается как ProviderError; реальные нулевые счётчики токенов сохраняются.
* Ошибки валидации больше не возвращают исходные пользовательские данные и корректно обрабатывают Infinity/NaN.

## [1.0.0] — 2026-10-24

Первый публичный релиз.

### Добавлено

* **Оценка процессов:** пригодность для ИИ, экономия времени, ROI и окупаемость с тремя сценариями, приоритизация
  по матрице «эффект — простота», дорожная карта по волнам, общий сервер self-hosted с итеративным пересчётом долей.
* **Подбор моделей:** жёсткие ограничения (политика данных, доступ из РФ, возможности, качество, бюджет), объяснимое
  ранжирование по четырём профилям, подсказки «что ослабить».
* **Безопасность данных:** поиск ФИО, телефонов, e-mail, ИНН, СНИЛС, карт, паспортов, адресов и секретов с контрольными
  суммами; обратимое обезличивание; матрица политики; памятка для сотрудников, генерируемая из политики.
* **Промпты:** 12 шаблонов по отделам, песочница Jinja2, линтер качества запросов, каркас запроса.
* **Оценка качества моделей:** харнесс с baseline на правилах, детерминированным симулятором и клиентом
  OpenAI-совместимых API; точность, F1, задержки, стоимость.
* **Интерфейсы:** CLI `compass`, REST API (FastAPI + SQLite), веб-дашборд (React + TypeScript), MCP-сервер
  (10 инструментов) для Claude Code, Codex, OpenCode и Kiro.
* **Инженерия:** `mypy --strict`, `ruff`, property-based тесты, тесты интерфейса (Vitest + Testing Library),
  CI (GitHub Actions), Docker, ежемесячная проверка свежести каталога моделей.
