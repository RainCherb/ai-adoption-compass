# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-24

### Добавлено

* Публичный read-only demo mode без SQLite, пользовательских загрузок и общего журнала; лимиты запросов и тела,
  предзагруженные 18 процессов, конфигурация Render Free, явное объяснение обработки данных.
* Реальные измерения трёх локальных LLM на 72 примерах: полные ответы, версии и хеши весов/runtime, параметры,
  проверка целостности артефакта, отдельная вкладка и REST API; симуляция сохранена как учебный режим.
* Реестр источников тарифов/доступа, нормализованные предложения OpenRouter, срок актуальности и происхождение,
  ревью с привязкой к SHA-256, еженедельный артефакт-кандидат без автоматической подмены каталога.

### Исправлено

* Ошибка 500 при переполнении расчёта очень большой стоимостью внедрения: введены числовые пределы и безопасные ошибки 422.
* Ошибочный формат usage провайдера обрабатывается как ProviderError; реальные нулевые счётчики токенов сохраняются.
* Ошибки валидации больше не возвращают исходные пользовательские данные и корректно обрабатывают Infinity/NaN.

## [1.0.0] — 2026-10-24

Первый публичный релиз.

### Добавлено

* **Оценка процессов:** пригодность для ИИ, экономия времени, ROI и окупаемость с тремя сценариями, приоритизация
  по матрице «эффект — простота», дорожная карта по волнам, общий сервер self-hosted с итеративным пересчётом долей.
* **Подбор моделей:** жёсткие ограничения (политика данных, доступ из РФ, возможности, качество, бюджет), объяснимое
  ранжирование по четырём профилям, подсказки «что ослабить».
* **Безопасность данных:** поиск ФИО, телефонов, e-mail, ИНН, СНИЛС, карт, паспортов, адресов и секретов с контрольными
  суммами; обратимое обезличивание; матрица политики; памятка для сотрудников, генерируемая из политики.
* **Промпты:** 12 шаблонов по отделам, песочница Jinja2, линтер качества запросов, каркас запроса.
* **Оценка качества моделей:** харнесс с baseline на правилах, детерминированным симулятором и клиентом
  OpenAI-совместимых API; точность, F1, задержки, стоимость.
* **Интерфейсы:** CLI `compass`, REST API (FastAPI + SQLite), веб-дашборд (React + TypeScript), MCP-сервер
  (10 инструментов) для Claude Code, Codex, OpenCode и Kiro.
* **Инженерия:** `mypy --strict`, `ruff`, property-based тесты, тесты интерфейса (Vitest + Testing Library),
  CI (GitHub Actions), Docker, ежемесячная проверка свежести каталога моделей.
