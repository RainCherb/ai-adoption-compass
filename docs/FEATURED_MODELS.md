# Основные зарубежные модели: тарифы и метод расчёта

Главный экран и первый пункт меню — **Зарубежные модели** (`#/models`). Порядок:
Claude Sonnet 5.5 → GPT-6.1 Sol → DeepSeek V4.1 Flash. Это редакционный порядок демо, а не рейтинг качества.
Дата сверки — **24 октября 2026**. Прямые API не вызываются: демо не требует ключей и не расходует средства.

| Модель | API ID | Вход / выход, USD за 1 млн токенов | Контекст по документации | Максимальный выход по документации |
| --- | --- | --- | --- | --- |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | $2 / $10, Standard global routing | 1M | 128K |
| GPT-6.1 Sol | `gpt-6.1-sol` | $2 / $10, Standard при входе ≤272 000 | 1 050 000 | 128 000 |
| DeepSeek V4.1 Flash | `deepseek-flash` | Peak $0.30 / $1.20; Off-peak $0.15 / $0.60 | 1M | 384K |

Источники: [Anthropic pricing](https://platform.claude.com/docs/en/about-claude/pricing),
[Anthropic model limits](https://platform.claude.com/docs/en/models/overview),
[OpenAI GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol),
[DeepSeek pricing and model details](https://api-docs.deepseek.com/quick_start/pricing/).
Документированная версия DeepSeek — **DeepSeek-V4.1-Flash-1017**. Имена API являются aliases и могут обновляться.
Для обозначений 1M/128K/384K калькулятор использует консервативные десятичные пределы; он не обещает весь объём,
который может фактически разрешить API. Сумма входа и выхода не должна превышать предел контекста калькулятора.

## Что именно считается

Одна текстовая нагрузка для каждой модели, USD, cache miss, без инструментов и региональной надбавки:

`месячная стоимость = запросы × (вход × тариф входа + весь оплачиваемый выход × тариф выхода) / 1 000 000`.

Расчёт использует Decimal, без промежуточного округления до центов. В интерфейсе отдельно показаны вход, выход,
месячная сумма и цена запроса; малые суммы не округляются до ложного нуля. Рублёвый эквивалент не показывается:
он потребовал бы актуального курса и учёта комиссий оплаты. Изменённая форма явно помечает прежний расчёт до отправки.

Контроль: **10 000 запросов × (1 000 входных + 300 выходных)** = 10 млн входных и 3 млн выходных токенов.

| Модель / режим | Вход за месяц | Выход за месяц | Итого | За запрос |
| --- | --- | --- | --- | --- |
| Sonnet 5.5 | $20 | $30 | **$50** | $0.005 |
| GPT-6.1 Sol, Standard | $20 | $30 | **$50** | $0.005 |
| DeepSeek Peak | $3 | $3.60 | **$6.60** | $0.00066 |
| DeepSeek Off-peak | $1.50 | $1.80 | **$3.30** | $0.00033 |

Это сравнение стоимости одинакового числа токенов, а не цены решения задачи одинакового качества.
Количество reasoning-токенов и повторов отличается между моделями; пользователь должен включить весь оплачиваемый
выход в нагрузку. Налоги, комиссии, инфраструктура, search/fetch и другие инструменты не входят в итог.

## Условия, которые нельзя смешивать

* **GPT:** при входе **более 272 000** токенов весь запрос имеет тариф $4 input / $15 output.
  Ровно 272 000 остаётся на $2/$10. Для одного запроса 272 001 input + 1 000 output итог **$1.103004**.
  Fast ×2, Ultrafast ×6, Batch/Flex −50%, regional processing +10% в калькулятор не включены.
* **Sonnet:** полный контекст по стандартному тарифу. US-only inference +10% и Batch −50% не включены.
  Cache read $0.10; запись 5 минут $2.50, 1 час $4 за 1 млн. Эти цены не подменяют обычный input $2.
* **DeepSeek:** Peak — понедельник–пятница, 01:00–04:00 и 06:00–10:00 UTC, кроме праздников Китая.
  Всё остальное время — Off-peak. По умолчанию выбран Peak; автоматического календаря с предположениями о
  праздниках нет. Для смешанной месячной нагрузки периоды считают отдельно. Cache hit $0.006 / $0.003
  не подменяет cache miss $0.30 / $0.15.

## Достоверность и обновление

Параметры и условия находятся в `data/featured-models.yaml`, источники — в `data/sources.yaml`, снимки —
в `data/source-snapshots.json`. Сверка помечена автором **Codex — сверка официальной документации**;
это не проверка человеком от имени владельца и не подтверждение доступа к API.

Для вычисления нужны доступные, не просроченные снимки со статусом `reviewed`, совпадающими URL, SHA-256,
датой ревью и закреплёнными в карточке хешами. Срок актуальности тарифов/лимитов — 7 дней. При несовпадении,
будущей дате или истечении TTL стоимость скрывается. Изменение источника требует повторной сверки значений
и обновления хеша в карточке; автоматическая загрузка HTML сама по себе не подтверждает тариф.

Еженедельный workflow создаёт **кандидат** обновления. Он не продлевает ревью и не публикует цены самостоятельно.
Процесс: [управляемые источники](CATALOG_SOURCES.md). Карточки ссылаются на прямые тарифы; старые предложения
OpenRouter остаются отдельными тарифами агрегатора для других точных model IDs.

Собственных измерений качества и задержки этих трёх моделей **нет**. Предыдущий бесплатный локальный эксперимент
с Qwen и SmolLM2 сохранён, с явным предупреждением, что его результаты не относятся к основным моделям.
Условный экспертный каталог в «Подборе моделей» нужен для примера политик данных и ROI; он не используется
для прямого тарифного сравнения. ПДн и конфиденциальные процессы не становятся допустимыми для зарубежного
API из-за нового акцента интерфейса.

РФ отсутствует в официальных списках стран [OpenAI API](https://developers.openai.com/api/docs/supported-countries)
и [Claude API](https://platform.claude.com/docs/en/api/supported-regions). Доступность DeepSeek, аккаунта,
платежей и допустимость передачи данных проверяются отдельно. Подписка ChatGPT/Codex не оплачивает OpenAI API.
