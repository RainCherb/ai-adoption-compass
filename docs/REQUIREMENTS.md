# Требования и трассировка

Документ показывает, **что** система должна делать, как это проверяется и где реализовано. Формулировки — в формате
«Как <роль>, я хочу <возможность>, чтобы <результат>» с проверяемыми критериями приёмки.

Роли: **внедренец** — специалист, который подбирает ИИ-инструменты и ведёт проект; **руководитель** — заказчик эффекта;
**сотрудник** — человек, который ежедневно работает с нейросетями; **ИБ** — специалист по информационной безопасности;
**разработчик** — тот, кто подключает инструмент к агентам и сервисам.

## Нефункциональные требования

| Область | Требование | Как обеспечено |
| --- | --- | --- |
| Приватность | Исходные тексты не сохраняются и не попадают в журнал и логи; API не обращается к внешним LLM | Журнал метаданных; превью без восстановления значения; тест `test_audit_log_keeps_metadata_only_never_texts` |
| Безопасность | Нет path traversal, инъекций в шаблоны, чрезмерных запросов | Проверки путей (API и MCP), Jinja2 `SandboxedEnvironment`, лимиты размеров, CSP |
| Воспроизводимость | Одинаковый вход → одинаковый результат | Детерминированный скоринг и симулятор; `COMPASS_TODAY` для проверок по дате |
| Качество кода | Строгая типизация, линтеры, покрытие тестами | `mypy --strict`, `ruff`, порог покрытия 85 % |
| Производительность | Расчёт портфеля из десятков процессов — доли секунды | Чистые вычисления без сетевых вызовов |
| Сопровождаемость | Данные меняются без правки кода | YAML с проверкой схем, `COMPASS_DATA_DIR` |
| Достоверность | Демонстрационные цены не выдаются за реальные | Статус каталога `illustrative`, предупреждения в UI, CLI, API и отчётах, ежемесячное напоминание |
| Доступность интерфейса | Клавиатура, контраст, подписи графиков | Семантическая вёрстка, `aria`-атрибуты, текстовые описания диаграмм |

## Что намеренно не входит в версию 1.0

* Аутентификация и ролевая модель — приложение рассчитано на локальный запуск и внутренний контур.
* Автоматическое получение актуальных цен провайдеров — данные вводятся и проверяются человеком.
* Вызов внешних LLM из API — это сознательное ограничение приватности; оценка на реальных моделях запускается из CLI.
