# Настоящие измерения LLM

На одном и том же наборе из 72 синтетических обращений проверены три открытые модели: Qwen2.5-0.5B-Instruct,
Qwen3-0.6B и SmolLM2-360M-Instruct. Это реальные локальные вызовы llama.cpp, не профили `sim:*`. Платные API не использовались.

| Провайдер | Точность | macro-F1 | Невалидных ответов |
| --- | --- | --- | --- |
| Правила (baseline) | 84,7 % | 0,854 | 0 |
| Qwen3-0.6B | 56,9 % | 0,548 | 0 |
| Qwen2.5-0.5B-Instruct | 36,1 % | 0,308 | 1 |
| SmolLM2-360M-Instruct | 0,0 % | 0,000 | 72 |

На этом наборе модели не прошли критерий «лучше baseline». SmolLM2 не соблюдала формат/категории в русскоязычной
инструкции; 72 невалидных ответа учитываются как ошибки, а не исключаются из знаменателя. Низкий результат не исправлялся
подбором удобных примеров или удалением неудачных ответов. Результат относится только к этим небольшим моделям и настройкам;
он ничего не доказывает о крупных моделях тех же семейств или промышленном качестве в целом.

## Воспроизведение

1. Установить проект с dev-зависимостями согласно README.
2. Скачать выбранный официальный runtime llama.cpp b11854 и три GGUF из URL манифеста, проверить SHA-256.
   Для Windows манифест включает CPU x64 ZIP; распаковать его в `.local/llama`. Веса сохранить в `.local/`.
   Для другой ОС использовать соответствующую сборку того же runtime, указав фактический путь в команде.
3. Запустить:

```bash
python scripts/run_local_benchmark.py --runtime .local/llama/llama-server.exe --manifest docs/benchmarks/local-manifest.json --models-dir .local --out src/adoption_compass/data/evals/measured.json
```

Прогон последовательно поднимает три сервера только на `127.0.0.1:8091` и завершает собственные процессы в `finally`.
Убедитесь, что порт свободен. При транспортных ошибках частичный результат не публикуется. Ожидается около 1,7 ГБ
весов; файлы `.local` исключены из Git и Docker context.

Параметры: Q8_0, 6 CPU-потоков, контекст 2048, один слот, без prompt cache, `temperature=0`, `max_tokens=64`;
thinking отключён для Qwen3. Одинаковые инструкции, категории, порядок и пользовательские примеры для всех моделей;
правильные метки не передаются модели. Железо и SHA-256 runtime указаны в артефакте. Задержки зависят от машины,
а фактическая стоимость электричества/оборудования не измерялась (`cost_rub=null`, внешний API-счёт 0 ₽).

Источник весов и лицензий — официальные карточки
