# Управляемые источники тарифов и условий доступа

`sources.yaml` задаёт разрешённые источники, точные модели, тип извлечения и срок актуальности. API и интерфейс читают
готовый `source-snapshots.json`, поэтому открытие каталога не делает внешних запросов.

| Источник | Что подтверждает | Срок |
| --- | --- | --- |
| Anthropic: pricing, models overview | Тарифы Claude Sonnet 5.5 и Haiku 5.5, контекст и предел выхода | 30 дней |
| OpenAI: страницы моделей | Тарифы, порог длинного контекста, контекст и выход GPT-6.1 Sol и GPT-6 Luna | 30 дней |
| DeepSeek: Models & Pricing | Пиковые и внепиковые тарифы V4.1 Flash и V4 Pro, контекст и выход | 30 дней |
| Yandex AI Studio: pricing | Рублёвые тарифы YandexGPT Pro 5.1 и Alice AI LLM с НДС | 30 дней |
| GigaChat API: тарифы для юрлиц | Рублёвые тарифы GigaChat 2 Max, Pro и Lite с НДС, минимальный платёж | 30 дней |
| GigaChat: страницы моделей | Контекст и возможности GigaChat 2 Max, Pro и Lite | 90 дней |
| Anthropic, OpenAI, DeepSeek: условия доступа | Поддерживаемые страны и регионы API | 90 дней |
| OpenRouter Models API | Тариф конкретного model ID у агрегатора — только для справки, не прямой тариф | 30 дней |

Срок актуальности — порог предупреждения: если снимок старше, расчёт показывается с пометкой «тариф сверялся N дн.
назад». Изменённый, неотревьюированный или «будущий» снимок блокирует расчёт полностью. Страница Yandex AI Studio отдаёт
роботам CAPTCHA: такой ответ не считается прайс-листом, поэтому ревью 25.10.2026 сделано по копии Wayback Machine
от 16.10.2026, что указано в заключении ревью.

Снимок содержит время получения UTC, SHA-256 содержимого, нормализованные предложения и статус:
`machine_checked`, `review_required`, `unavailable` или `reviewed`. Страница с CAPTCHA/редиректом не считается прайс-листом.
Отрицательные, нечисловые, бесконечные цены, изменение формата и исчезновение выбранной модели отклоняются. Нулевая цена
допустима; она не доказывает отсутствие квот или региональных ограничений. Недоступные тарифы не показываются как актуальные.

## Обновление и ревью

```bash
compass catalog sources
compass catalog refresh-sources --out candidate/source-snapshots.json
```

Вторая команда явно обращается к сети. Она не перезаписывает основной каталог. При недоступном источнике возвращается
код 1, но JSON с объяснением остаётся доступен. Все URL должны быть HTTPS на разрешённых официальных доменах;
редиректы и ответы более 8 МБ запрещены. Нет сетевого маршрута обновления в REST API.

Еженедельный workflow `Catalog source review` и ручной `workflow_dispatch` формируют 30-дневный артефакт
`catalog-source-candidate`. Он содержит кандидата для проверки, не коммитит его в `main` и не меняет цены без ревью.

После проверки содержимого, валюты/единиц, НДС, режима API, региона и даты можно зафиксировать заключение:

```bash
compass catalog review-source candidate/source-snapshots.json --source-id sber-gigachat-pricing --sha256 <проверенный-хеш> --reviewer "Имя ревьюера" --note "Сверены тарифы pay-as-you-go с НДС и минимальный платёж; заключение ..."
```

Ревью привязано к точному SHA-256. Подтвердить другой или недоступный снимок нельзя. При новом получении источника старое
подтверждение не переносится. Кандидат после проверки переносится в `src/adoption_compass/data/source-snapshots.json`
и поступает через обычный PR с CI. Для добавления нового официального источника также нужно изменить код allowlist и тесты.

## Почему основной каталог остаётся illustrative

Строки каталога описывают классы моделей, а не точные версии провайдеров. Цена OpenRouter для конкретного ID не равна
цене прямого API. Автоматически заменить одно другим было бы ошибкой. Предложения источников видны отдельно на вкладке
«Каталог»; их можно использовать после проверки конкретного способа подключения. Доступность и качество 1–5 не выводятся
из HTTP 200, цены или размера контекста. Для перевода всего каталога в `verified` нужна поэлементная проверка,
а для эмпирических оценок качества — отдельные релевантные тесты.
