# Подключение к ИИ-агентам по MCP

`compass mcp` запускает [MCP](https://modelcontextprotocol.io/)-сервер по stdio. Агент получает десять инструментов:
проверка данных перед отправкой в модель, подбор моделей, оценка процессов, библиотека и линтер промптов.

## Установка

```bash
pipx install git+https://github.com/RainCherb/ai-adoption-compass   # или: pip install -e . из клона
compass mcp --help
```

Если `compass` установлен в виртуальное окружение, в конфигурациях ниже укажите абсолютный путь к исполняемому файлу
(например, `/home/me/ai-adoption-compass/.venv/bin/compass`).

## Конфигурация клиентов

Форматы сверены с документацией клиентов на 24.10.2026; если клиент обновился, ориентируйтесь на его документацию.

### Claude Code

```bash
claude mcp add --transport stdio --scope project compass -- compass mcp --root .
```

Или вручную, файл `.mcp.json` в корне проекта:

```json
{
  "mcpServers": {
    "compass": { "command": "compass", "args": ["mcp", "--root", "."] }
  }
}
```

### Codex CLI

```bash
codex mcp add compass -- compass mcp --root .
```

Или в `~/.codex/config.toml`:

```toml
[mcp_servers.compass]
command = "compass"
args = ["mcp", "--root", "."]
```

### OpenCode

`opencode.json` в корне проекта:

```json
{
  "mcp": {
    "compass": {
      "type": "local",
      "command": ["compass", "mcp", "--root", "."],
      "enabled": true
    }
  }
}
```

### Kiro

`.kiro/settings/mcp.json` (в проекте) или `~/.kiro/settings/mcp.json` (для пользователя):

```json
{
  "mcpServers": {
    "compass": {
      "command": "compass",
      "args": ["mcp", "--root", "."],
      "disabled": false
    }
  }
}
```

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `scan_sensitive_data(text, declared_sensitivity)` | находит ПДн и секреты; возвращает находки **с маскированными превью** и решение `allow` / `mask` / `deny` для российского облака, зарубежного облака и self-hosted |
| `mask_sensitive_data(text)` | заменяет значения метками `[PHONE_1]`; соответствия **не возвращает** |
| `scan_file(path)` | то же для локального файла внутри разрешённой папки; агент не видит содержимое |
| `mask_file(path, output_path?, overwrite?)` | пишет обезличенную копию и файл соответствий (права `600`); возвращает только имена файлов и счётчики |
| `recommend_models(...)` | подбор моделей под задачу, категорию данных, бюджет и доступность из РФ; пояснения «почему нет» |
| `assess_ai_use_cases(processes, assumptions?, top?)` | приоритизация процессов: пригодность, ROI, квадранты, дорожная карта |
| `lint_prompt(text)` | оценка запроса 0–100 по чек-листу |
| `list_prompt_templates(department?)`, `render_prompt_template(id, values)` | библиотека готовых шаблонов |
| `check_catalog_freshness(max_age_days?)` | какие записи каталога давно не проверялись |

Ресурс `compass://policy/handout` отдаёт памятку для сотрудников в формате Markdown.

## Модель приватности

Агент — это модель, и всё, что он передаёт в аргументах инструмента, уже находится в её контексте. Поэтому:

* обезличивание **текста из чата** защищает только то, что будет отправлено *дальше*;
* для реальных данных используйте `scan_file` и `mask_file`: файл читается локально, а агент получает лишь метаданные;
* файл соответствий (`*.mapping.json`) содержит исходные значения — не передавайте его в сервисы и не коммитьте;
* файловые инструменты работают только внутри `--root` (или `COMPASS_MCP_ROOT`); пути с `..`, абсолютные пути
  и симлинки наружу отклоняются;
* ожидаемые ошибки (неверный параметр, файл не найден) возвращаются как `is_error` с понятным текстом.

## Примеры запросов к агенту

* «Проверь `exports/customers.csv` инструментом `scan_file` и скажи, можно ли отправлять его в зарубежное облако.»
* «Подбери модель для классификации 20 тысяч обращений в месяц с персональными данными, бюджет до 20 000 ₽.»
* «Вот список из шести процессов отдела — прогони `assess_ai_use_cases` и предложи порядок внедрения.»
* «Оцени этот промпт `lint_prompt` и перепиши так, чтобы получить оценку A.»

## Диагностика

| Симптом | Причина и решение |
| --- | --- |
| Клиент не видит сервер | проверьте, что команда запускается в терминале; укажите абсолютный путь к `compass` |
| «Путь вне разрешённой папки» | файл лежит за пределами `--root`; запустите сервер из нужной папки или задайте `COMPASS_MCP_ROOT` |
| Сервер падает при старте | в stdio-режиме нельзя печатать в stdout: не добавляйте `print` в код сервера |
| Данные каталога «демонстрационные» | это ожидаемо: сверьте тарифы и обновите `catalog.yaml` (`COMPASS_DATA_DIR`) |
