# AGENTS.md — инструкции для ИИ-агентов и контрибьюторов

Проект: **AI Adoption Compass** — инструменты внедрения ИИ в компании (оценка процессов и ROI, подбор моделей,
защита данных, шаблоны промптов, оценка качества моделей, REST API, MCP-сервер, веб-дашборд).

## Карта репозитория

| Путь | Что там |
| --- | --- |
| `src/adoption_compass/` | Python-пакет (движки, API, CLI, MCP). Данные — в `data/*.yaml`, `data/samples`, `data/evals` |
| `tests/` | pytest + Hypothesis; общие фикстуры в `conftest.py`, генераторы синтетических ИНН/СНИЛС/карт — в `factories.py` |
| `web/` | React + TypeScript (Vite, Vitest); сборка попадает в `src/adoption_compass/static` |
| `docs/` | методология, архитектура, MCP, требования, плейбук, обучение; `openapi.json` — контракт API |
| `scripts/` | `export_openapi.py`, `capture_screenshots.py`, `render_cli_demo.py` |

## Команды

```bash
make install        # окружение и зависимости
make check          # линтеры + mypy + pytest + проверка OpenAPI + проверки фронтенда
make test           # только бэкенд
make web            # собрать интерфейс
make openapi        # обновить docs/openapi.json и TypeScript-типы после изменения API
make run            # http://127.0.0.1:8000
```

## Правила

1. **Определение готовности:** `make check` зелёный; для нового поведения есть тест; документация обновлена.
2. **Данные — в YAML, не в коде.** Цены, оценки, политика, допущения и шаблоны правятся в `src/adoption_compass/data`.
   Новые поля сначала добавляются в схему Pydantic.
3. **API-контракт.** Меняете схемы или маршруты — запустите `make openapi` и закоммитьте `docs/openapi.json`
   и обновлённые типы фронтенда; `tests/test_docs_sync.py` проверит синхронность.
4. **Приватность.** Не логируйте и не сохраняйте исходные тексты; находки показывайте только через `preview`.
   В тестах и документации используйте синтетические данные: ИНН, СНИЛС и карты генерируются в `tests/factories.py`,
   а токеноподобные строки собираются в рантайме (см. `SECRETS` в `tests/test_safety.py`), чтобы в репозитории
   не было литералов, похожих на настоящие ключи.
5. **MCP-сервер работает по stdio — в stdout писать нельзя.** Ожидаемые ошибки оформляйте как `ToolError`.
6. **Интерфейс на русском.** Тексты для пользователей — русские; идентификаторы и поля API — английские.
7. **Формулы и документация.** Меняете расчёт — обновите `docs/METHODOLOGY.md` (пример в нём проверяется тестом).
8. **Не добавляйте** аутентификацию «на скорую руку», внешние сетевые вызовы из API и телеметрию.
9. Стиль: `ruff` (длина строки 100), `mypy --strict`, типы везде, комментарии только о неочевидном.
